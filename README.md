# TecnoStock - Sistema de Inventario

Sistema web desarrollado para la asignatura de Sistemas de Información.

## Descripción
Aplicación web que permite gestionar el inventario de productos de un emprendimiento tecnológico. Reemplaza el uso de planillas de Excel para evitar códigos duplicados y errores de stock.

## Tecnologías usadas
- PHP 8 con PDO
- MySQL
- Bootstrap 5
- XAMPP (servidor local)
- JavaScript para validaciones

## Funcionalidades
- Login de usuarios
- Crear, editar y desactivar productos
- Búsqueda por nombre, código o categoría
- Registro de entradas y salidas de stock
- Alerta visual de stock bajo
- Actualización automática del stock

## Instalación
1. Instalar XAMPP
2. Copiar la carpeta `tecnostock` en `C:\xampp\htdocs\`
3. Iniciar Apache y MySQL desde el panel de XAMPP
4. Abrir en el navegador: `http://localhost/tecnostock/instalar.php`
5. Iniciar sesión con:
   - Usuario: `admin@tecno.com`
   - Clave: `1234`
